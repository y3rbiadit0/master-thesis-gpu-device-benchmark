\section{Composite Sequence}

Figure~\ref{fig:app-cg-all} shows every measured multi-rank \texttt{cg\_step} topology. The single-rank control is omitted because it performs no inter-rank communication. Ratios use the CUDA MPI median at the same topology and global side as a fixed denominator; the bands do not propagate uncertainty in that denominator. In the measured OSHMPI implementation, the reduced scalars remain in host memory and are not copied back to the GPU.
